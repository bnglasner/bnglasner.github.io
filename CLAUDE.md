# CLAUDE.md — entry point for Claude in this repo

This is Benjamin Glasner's personal academic portfolio (al-folio Jekyll). Two layers of agent guidance live in this repo:

- **`@AGENTS.md`** — al-folio template guidance (build, dev workflow, file-type instructions). Inherited from upstream. Treat as authoritative on Jekyll/Liquid/Docker mechanics.
- **`.claude/`** — Ben-specific guidance for maintaining _this_ portfolio. Treat as authoritative on what content belongs on the site, how it should sound, and how to verify changes before commit.

When the two conflict, `.claude/` wins for any decision about content, voice, or release readiness; `@AGENTS.md` wins for build mechanics.

## How Ben wants Claude to work in this repo

Standing rules every task should respect, regardless of which skill or agent is active:

- Propose a plan before any non-trivial task. Flag your interpretation if the request can be read more than one way; do not silently pick.
- Prefer small, reversible changes. Name tradeoffs when the choice is non-obvious.
- Verify before declaring completion: run the build, spot-check outputs, confirm referenced files exist.
- Do not summarize what you just did at the end of a response. Ben can read the diff.
- For outputs with factual claims, include an Evidence block with **Sources**, **Confidence** (High/Medium/Low), and **Assumptions**. Skip it for purely mechanical work.

## Hard "do not" list

- Do not present co-authored work as solo. Every entry in `_data/writing.yml` must carry an `authors` field. A pre-commit hook enforces this.
- Do not surface non-Ben content on the personal site. The EIG-Research GitHub organization is the only institutional carve-out.
- Do not overwrite `_data/{publications,mentions,media,cv_assets,citations,repositories}.json` or `_data/citations.yml` by hand. The first set is generated by the retired profile-sync pipeline (now repo-authoritative — leave alone unless asked); `citations.yml` is updated by `.github/workflows/update-citations.yml`.
- Do not commit `_site/`, `.jekyll-cache/`, or other generated output (already in `.gitignore`).
- Do not modify `_config.yml` `url` or `baseurl` without updating both together.
