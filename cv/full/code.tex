\entry*[2026]%
    \textbf{\href{https://github.com/EIG-Research}{Reproducible Research Pipeline and GitHub Standards at EIG}}
    \par Economic Innovation Group (EIG)
    \par Implemented a rigorous, fully transparent, and replicable data and analysis pipeline for public-facing economic research, and built and trained staff workflows for GitHub collaboration, code review, documentation, and reproducibility best practices.
    \par \href{https://github.com/EIG-Research}{EIG-Research}, \href{https://github.com/bnglasner}{bnglasner}
\entry*[2026]%
    \textbf{\href{https://bnglasner.github.io/ai-research/}{AI-Assisted Research Infrastructure at EIG}}
    \par Economic Innovation Group (EIG)
    \par Designed and maintain EIG's AI-assisted research template, which brings AI coding agents into empirical projects under standards for code review, methodology, verification of reported numbers, reproducibility, and disclosure of AI use. Designed and prototyped a structured knowledge base that makes institutional knowledge readable by both staff and AI agents.
    \par \href{https://bnglasner.github.io/ai-research/}{Overview}
\entry*[2026]%
    \textbf{\href{https://github.com/EIG-Research/EIG-Retirement-Fast-Facts-replication}{The U.S. Retirement System: Fast Facts (Replication Package)}}
    \par GitHub (EIG-Research)
    \par R pipeline characterizing retirement plan access, participation, and employer contributions for 147 million civilian workers from SIPP microdata, with a present-value estimate of the federal retirement tax expenditure and a testthat suite of invariant checks.
    \par \href{https://github.com/EIG-Research/EIG-Retirement-Fast-Facts-replication}{Code}, \href{https://eig.org/retirement-fast-facts/}{Website}
\entry*[2026]%
    \textbf{\href{https://github.com/EIG-Research/EIG-Savers-match-sipp}{Saver's Match: Eligibility and Cost Analysis (Repository)}}
    \par GitHub (EIG-Research)
    \par Eligibility, access-gap, and fiscal-cost microsimulation of the SECURE 2.0 Saver's Match from SIPP microdata, replicating the Joint Committee on Taxation score and costing expanded and universal designs.
    \par \href{https://github.com/EIG-Research/EIG-Savers-match-sipp}{Code}
\entry*[2025]%
    \textbf{\href{https://github.com/EIG-Research/oz-housing-supply}{The Impact of Opportunity Zones on Housing Supply (Repository)}}
    \par GitHub (EIG-Research)
    \par Difference-in-differences analysis using HUD USPS Administrative Data on Address Vacancies. Estimates suggest Opportunity Zones increased new residential addresses in treated low-income communities.
    \par \href{https://github.com/EIG-Research/oz-housing-supply}{Code}, \href{https://eig.org/opportunity-zones-housing-supply/}{Website}, \href{https://eig.org/wp-content/uploads/2025/02/The_Impact_of_Opportunity_Zones_on_Housing_Supply.pdf}{PDF}
\entry*[2024]%
    \textbf{\href{https://github.com/EIG-Research/EIG-Great-Transfer-Mation}{The Great "Transfer"-mation (Repository)}}
    \par GitHub (EIG-Research)
    \par County-level analysis of the growth of government transfer income as a share of personal income since 1970. Data and replication code supporting EIG's report and interactive.
    \par \href{https://github.com/EIG-Research/EIG-Great-Transfer-Mation}{Code}, \href{https://eig.org/great-transfermation/}{Website}, \href{https://eig.org/wp-content/uploads/2024/09/Great-Transfermation.pdf}{PDF}
